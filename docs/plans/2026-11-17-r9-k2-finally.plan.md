## Formal Plan
1. Failing test first (`tests/differential.rs`, `agree_out_php`: three legs plus the expected output), confirmed red on
   the VM for the stated reason. Cases: a throw from a catch body; a callee that throws from a catch body; `throw e;`
   rethrowing the bound value; locals declared in the catch body and in `finally` (slot alignment); two nested
   try/catch/finally in one function; for each exit of a catch body (fall-through, `return`, `break`, `continue`) the
   next event is a caught throw from the caller, so a leaked handler shows; a hot variant (the function called in a
   loop, and a `try` inside a loop) so the JIT compiles it.
2. Fix in `compile_try` (`src/compiler/stmt/loops.rs`): when `finally` exists, each catch-clause body runs under its
   own `PushHandler` (height `v_slot + 1`); its fall-through emits `PopHandler` before the inline `finally`; its
   `TryCtx` carries `has_handler: true` so `return`/`break`/`continue` pop it; its landing pad (after the clause's
   `Jump end`, before the next clause) registers the new exception as a local at `v_slot + 1`, runs `finally`, and
   re-throws. No `finally`: unchanged.
3. JIT: `PHORJ_JIT_EXPLAIN=1` on the hot variant before and after; a function that compiled before and declines after
   is recorded as a perf cliff, not passed.
4. Sabotage: drop the fall-through `PopHandler`, and set `has_handler` back to false; each must turn the test red.
5. One catch-throws-with-finally case in `examples/guide/errors.phg` (the corpus glob gates it on three legs).
6. Full correctness gate, release binary, SLICE-STATE (entry FIXED), CHANGELOG, `scripts/size-gate.sh` after
   `cargo fmt`.
