## Roles and mental models
- **Tooling owner under the 100% rule**: "done" means the RUNNING server answers (hover, definition, references, symbols, signature help), not that the compiler knows; drive the server rather than reading the code.  [Source: memory/l4-named-tuples-gate-lessons.md; memory/editors-same-change-checklist.md]
- **Supply-chain gatekeeper**: the core stays std-only; anything linked into a produced binary or its runtime stays std-only too (hand-rolled ELF/PE/Mach-O readers, CRC-32, SHA-256); build tooling (zig, cargo-zigbuild, llvm-objcopy, signers, CI) is exempt. Test: "does it end up linked into the artifact?"  [Source: docs/specs/UNIFIED-SPEC.md:2627-2634]
- **Gate skeptic**: a gate proves only what it executed; count what ran, read the job's own line, never a wrapper's exit status.  [Source: memory/economize-tokens-panels-and-compaction.md; memory/consolidation-session-2026-09-02-gotchas.md]

## Classic failure modes (with detection)
- **Gate scope lies** (four mechanisms): `cargo nextest -E 'test(x)'` filters on test NAME (it printed "9 passed" while 3 of 4 handshake tests never ran) - select binaries (`--lib`, `--test <name>`) and assert N > 0; `cmd | tail` reports tail's status (use `${PIPESTATUS[0]}` or the job's own line); wrapping a gate leg in `$( ... | grep -c ...)` printed "0 warnings" while clippy had 2 errors; a coverage ratchet measured what tests MENTIONED, not what ran.  [Source: memory/gate-filters-and-untracked-files.md; memory/consolidation-session-2026-09-02-gotchas.md; memory/build-queue-cursor-2026-07-16.md; memory/big-wave-2026-09-05.md]
- **Sabotage that proves nothing**: a mutation that does not COMPILE (an unused binding under `warnings = "deny"`) leaves a `grep "test result"` empty, so grep for `test result|^error` and print the exit code; nextest reports killed tests as SIGKILL/SIGABRT/TIMEOUT, not FAIL; take the mutation pattern AFTER `cargo fmt` (fmt reflows match arms) and assert it occurs exactly once; restore with a byte copy then `touch` the file, because a restore that keeps the old mtime makes cargo run the MUTATED build; run an unmutated baseline first.  [Source: memory/sabotage-harness-silent-noncompile.md; memory/sabotage-restore-mtime-trap.md; memory/consolidation-session-2026-09-02-gotchas.md]
- **Formatter drops meaning**: it once dropped top-level visibility (`internal function` became public), clone-with `=`, interpolation-hole escaping and parens around lambda/if/match receivers. Detect: the idempotence-and-behaviour corpus test after ANY AST change.  [Source: memory/phg-fmt-milestone.md; tests/format.rs:117]
- **Two gates over one generated artifact** need ONE producer (lift examples vs the formatter); a prose guarantee with no test is false (the `helper_buckets` header "cannot drift").  [Source: memory/two-gates-one-artifact.md; memory/ssot-bookkeeping-traps.md]
- **Bookkeeping drift**: SLICE-STATE once trailed a full wave (four BUILT features recorded "build queued"); doc-guards G3 refuses a bare SHA in docs/plans (pre-push only); the progress-block `Files` column is space-separated.  [Source: .claude/agents/completeness-reviewer.md:107-109; scripts/doc-guards.sh:9; memory/progress-block-vs-doc-guards.md]
- **Stale signals**: a stale release binary (rebuild before probing shipped behaviour), a stale worktree base, a broken `core.hooksPath` that silently voided the pre-commit gate, a killed session leaving HEAD clippy-red behind a green pre-commit.  [Source: memory/session-2026-07-16-full-reopen-audit.md; memory/session-2026-07-15-fable-handover.md]
- **Inherited git environment**: a test or tool that shells out to git from inside an agent worktree inherits `GIT_DIR`/`GIT_WORK_TREE` and writes into the wrong repo; the package fetcher scrubs every inherited `GIT_*` variable, and any new git call needs the same.  [Source: memory/agent-worktree-vendor-git-corruption.md; src/pm/fetch.rs:165-169]
- **Partial undo**: `git checkout -- <file>` reverts EVERY edit in that file; never `git add -A` here; stage by path.  [Source: memory/consolidation-session-2026-09-02-gotchas.md; memory/session-2026-07-16-fable-overnight-run.md]
- **Killed cargo**: a mid-link kill shows as `undefined hidden symbol ... .llvm.` link errors, which means "cache poisoned", not "my code broke the linker"; recover by deleting `target/debug/incremental` with `find <dir> -depth -delete` (a plain recursive `rm` may be refused here), then `cargo clean -p phorj`.  [Observed: memory/detached-setsid-builds.md, 2026-10-08; memory/readiness-wave-2026-09-04-state.md]
- **Stale stub** embeds the source into an OLD VM and breaks the spine at the distribution layer; the cache key includes the `phg` binary hash. PE section embedding with `llvm-objcopy --add-section` needs `--set-section-flags NAME=noload,readonly`.  [Source: docs/specs/UNIFIED-SPEC.md:2623-2625; memory/pe-objcopy-section-flags.md]

## Reviewer lenses
1. **Completeness** - tests executed (count up, fails without the change), the four Rule-6 dimensions, blast radius grepped by the reviewer, the original request re-read; "a follow-up" is not completeness.  2. **Safety promises** - `unsafe` outside `src/jit/`, a deny widened to allow, TLS skip-verify, SQL string interpolation, a touched `bench/*-baseline.json`, a new crate without its policy row.  3. **Surface parity** - `phg check` vs LSP diagnostics, both editors and the grammar in the same change, a completion catalog sourced from the checker's resolved imports.
