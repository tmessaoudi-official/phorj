## 0. What a generic engineer gets wrong here (read this first)
1. Adds a deprecation shim. Pre-1.0 nothing is deprecated (DEC-416): a retired form is changed outright, examples updated in the same change, no compat twin, grace window or migration hint; the old name is an ordinary unknown-name error. `W-DEPRECATED` is now a userland attribute only.  [Source: docs/DEPRECATION.md:3-13]
2. Lets a name appear "from the wind". Every symbol (type, attribute, keyword-like verb, function) is reachable only through an explicit import; a bare injected type is `E-INJECTED-TYPE-BARE`. This is the most frequent design error here: DI `#[Injectable]` and `#[Route]` were once recognised by a bare string match.  [Source: memory/nothing-in-the-wind-import-discipline.md; src/checker/enforce_injected.rs:18]
3. Proposes something already rejected: `__get`/`__set`/`__call` magic, `&$x` references, `(int)` casts, C-style `switch`, operator overloading, async/await, `__destruct`, gradual typing with `mixed` holes, dynamic reflection by string, TypeScript utility types. Grep the catalogue, MASTER-PLAN and the register before any design question.  [Source: docs/specs/UNIFIED-SPEC.md:1894-1921; memory/rejected-typescript-utility-types.md; memory/search-specs-before-design-questions.md]
4. Trusts a document's own status. The pending-surface banners at the top of UNIFIED-SPEC supersede the section prose below them; a spec headed "not yet built" had shipped weeks earlier (3 of 11 on 2026-09-02); older sections are not always marked superseded. Grep `src/` for the spec's diagnostic codes and read the register row.  [Source: docs/specs/UNIFIED-SPEC.md:28-77; memory/consolidation-session-2026-09-02-gotchas.md; docs/specs/2026-07-23-typed-lsb.md:3]
5. Quotes a number from prose. Counts in the docs drift: INVARIANTS T-2b says `Expr` has 37 variants (the enum has 38); ADR-0001, ARCHITECTURE and UNIFIED-SPEC give three different trait counts; README says 14 crates in one place and 15 in another. Re-derive from code before stating any count.  [Source: docs/INVARIANTS.md:48; docs/ARCHITECTURE.md:90; README.md:6; README.md:93]
6. Reads a green differential as proof. `agree()` is a bare `tree == vm`, so a program both backends reject identically passes (pair it with the expected output); a bare zero-payload variant arm matched everything on both legs alike (now `E-MATCH-BARE-VARIANT`); the example glob ran nothing for weeks while green. Read the `CorpusTally` run counts, not the pass line.  [Source: tests/differential.rs:64-72; memory/zero-payload-variant-call-form.md; memory/example-glob-noop-since-dec191.md; tests/differential.rs:1892]
7. Lets bad input panic. A malformed `.phg` must exit 1 with a `Diagnostic`, never panic (EV-7); recursion is bounded by `src/limits.rs` on a 256 MB worker thread (`on_deep_stack`), so a test of a depth guard needs its own big-stack thread: the harness's small default test-thread stack can overflow before the guard fires.  [Source: docs/INVARIANTS.md:127-148; src/limits.rs:21-39; src/cli/pipeline.rs:13; memory/m-lift-l2-php-parser.md; memory/core-reflect-and-rewrite-gotcha.md]
8. Writes "as every leg does" without running the legs. A behaviour claim in a comment or commit message is a claim: run all three legs on the pre-fix binary first, and rebuild the release binary before probing shipped behaviour.  [Source: memory/audit-2026-10-07-ruled.md; memory/session-2026-07-16-full-reopen-audit.md]
9. Records an autonomous design call as `ASSUMED (review)`. An Invariant-15 question in autonomous mode is a `PENDING (Invariant 15)` row in the decision register plus a SLICE-STATE cursor line; global /next and /progress surface only ASSUMED, so a plan Decisions-Log bullet would be lost.  [Source: .claude/skills/phg-ask-human/SKILL.md:54-62]
10. Trusts a gate's scope. `cargo nextest -E 'test(x)'` filters on test NAME, not binary (select binaries, assert N > 0); a sabotage restore that keeps the old mtime makes cargo run the mutated build (`touch` after restoring). Recipes: tooling pack.  [Source: memory/gate-filters-and-untracked-files.md; memory/sabotage-restore-mtime-trap.md]
